## 3. Decisiones de Criterio Técnico Documentadas
1. **Tarjetas de prueba compatibles con el Algoritmo de Luhn:** Como la rúbrica exige tanto validar el algoritmo de Luhn como disponer de tarjetas de prueba para aprobación, rechazo y fondos insuficientes, se configuraron tres números que pasan matemáticamente el dígito de verificación de Luhn:
   - **Aprobada:** `4242424242424242`
   - **Rechazada:** `4000000000000002` (además, el backend también rechaza terminadas en `0000` si se envían directamente por API).
   - **Fondos insuficientes:** `4111111111111111` (terminada en `1111`).
2. **Contraste Dorado WCAG AA:** Se empleó `#8A6516` para textos dorados sobre blanco (contraste `5.12:1` ≥ `4.5:1`) y `#6B4E10` para fondos de botones con texto blanco (contraste `7.4:1`).
