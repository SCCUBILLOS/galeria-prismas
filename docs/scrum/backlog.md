# Product Backlog — Galería Prismas (Scrum)

**Equipo de Desarrollo:** Sara Cárdenas, Nicolás Molina, Brayan Gómez  
**Asignaturas:** Programación Web y Arquitectura de Información — Universidad Libre (2026-II)  
**Metodología:** Scrum (4 Sprints de 1 semana · Estimación en serie Fibonacci: 1, 2, 3, 5, 8, 13)

---

## Épicas del Proyecto

| Código | Épica | Descripción |
| :--- | :--- | :--- |
| **EP-01** | Estructura, Navegación y Accesibilidad | Layout semántico HTML5, header sticky, buscador global con autocompletado, migas de pan y barra WCAG 2.1. |
| **EP-02** | Catálogo de Obras, Favoritos y Carrito | Catálogo con filtros laterales, ficha técnica, favoritos, carrito con control de stock y vistas recientes. |
| **EP-03** | Artistas y Curaduría | Directorio de artistas representados, biografías, trayectoria y obras asociadas. |
| **EP-04** | Exposiciones y Reserva de Entradas | Agenda curatorial (En curso, Próximo, Finalizado), calendario y flujo de reserva de entradas con control de cupos. |
| **EP-05** | Cursos, Talleres e Inscripciones | Catálogo de talleres por nivel y modalidad, horarios, materiales incluidos, instructor y formulario de inscripción. |
| **EP-06** | Nosotros, Legal, PQR y Equipo (API Virtual) | Acordeón corporativo, mapa Google Maps, política Ley 1581, sistema PQR con radicado y CRUD de desarrolladores en `json-server`. |
| **EP-07** | Backend Express, Base de Datos, Inventario y Pagos | API REST en capas, Prisma + SQLite, autenticación JWT, pasarela ficticia con Luhn, facturación PDF y reportes gerenciales. |
| **EP-08** | Inteligencia Artificial, Calidad W3C y Documentación | Asistente curatorial Prisma IA con fallback local, pruebas automáticas (Jest/Vitest), validaciones W3C/Lighthouse y Documento Final. |
